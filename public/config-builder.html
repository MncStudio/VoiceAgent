VoiceAgent 配置生成器

输出文件名固定为 server/config/local.json —— 服务启动默认就加载它,不用起配置名。ASR / LLM / TTS 三个环节互相独立选 provider(内网自建选 http 档,百炼 / DeepSeek / 语析选 ws / openai 档,任意混搭)。
用法:填参数 → 「生成并下载 local.json」→ 放进目标机器 server/config/ → npm start。
⚠️ 配置含 API key(明文),只放进目标机器 server/config/(该目录已被 .gitignore 排除),别提交、别外发。
🚀 配置引导:当前服务没有可用配置。填好参数点「生成并下载」得到 local.json,把它放进本机 server/config/,再重新 npm start 即完成初始化(想改就再下载覆盖,不用删旧文件)。
输出文件名固定为 local.json;想并存多套,下载后改名再用 VA_PROFILE=<名字> 指向
