VoiceAgent 接口演示

本页即接入示例,只调用 VoiceAgent SDK 一个入口,可直接移植到你的前端项目
WebSocket 唤醒词监听
连接 /api/wake?sessionId=…,持续发送 16k mono int16 PCM 块(二进制)。 后端用 VAD+ASR 检测唤醒词(可改 server/config/*.json 的 wakeWords), 命中后去掉唤醒词、剩余文本送 LLM,自动回答并经 /api/tts 流式播放。 命中即进入唤醒窗口(wakeTimeout 秒):窗口内说话免唤醒词直接回答, 超时自动休眠,需重新说唤醒词。页面加载即自动开始监听。

POST 语音问答 /api/chat
multipart/form-data:audio(webm/mp4 录音)+ sessionId → 后端转码→VAD 裁静音→ASR→LLM,返回 {replyText, userText}; 音频由前端经 /api/tts 流式合成播放(边生成边播,无需等整段)。
松开发送
POST 文字问答 /api/chat_text
application/json:{"text":"…","sessionId":"…"} → 跳过 ASR,直接 LLM,返回 {replyText, userText};音频同样走 /api/tts 流式播放。 与语音/唤醒共享同一份多轮记忆。
