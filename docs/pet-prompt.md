# VoiceAgent 数字人形象唯一标准

本文件是 `VoicePet` 形象生成、验收和替换的唯一标准。把“生成提示词”一节连同角色描述或参考图交给图像生成工具；生成后必须按“验收清单”检查，全部通过才能放入项目。

## 文件与安装

每套形象只包含一对同名文件：

```text
public/pets/<英文名>.png
public/pets/<英文名>.json
```

放入目录并刷新页面后，`GET /api/pets` 会自动发现，页面的形象下拉框会自动出现该角色。不需要修改渲染代码。

标准 PNG 固定为透明 `1024×1024`，由 `8×8` 个 `128×128` 单元格组成。运行时仍兼容其他可整除尺寸以及旧版 PNG/WebP，但新形象一律按本标准生成。

## 生成提示词

```text
为 VoiceAgent 生成一张可直接用于程序切帧的数字人精灵图集。

角色：【填写形象描述；如果同时提供参考图，以参考图中的同一角色为准】。

输出要求：
1. 只输出一张 1024×1024 RGBA PNG，背景真正透明；不要说明文字。
2. 图片是严格的 8 列×8 行网格，共 64 个 128×128 单元格；不得绘制网格线、边框、编号、文字、背景、地面或水印。
3. 每格只有一个完整角色。角色在每格内水平居中、脚部基线一致、比例一致，四边至少保留 10px 完全透明安全区；任何像素不得触碰或跨越单元格边界。
4. 64 帧必须是同一角色：脸型、发型、服装、配色和身体比例一致。除当前动作涉及的部位外，其余部分保持不变；不得左右漂移、忽大忽小或改变服装。

从上到下的动作行固定如下，每行正好 8 帧：
- row0：克制的待机呼吸和一次眨眼，动作幅度很小。
- row1：说话口型。col0 完全闭口，col1 到 col7 的嘴巴宽度和高度严格单调递增，col7 最大张口；头、眼、头发、身体、手、衣服、位置和比例完全不动，只有嘴变化。
- row2：克制挥手，动作起止自然。
- row3：原地跳跃，蹲下→起跳→最高点→落地；只能垂直移动，不得水平漂移或缩放。
- row4：失败或沮丧反应。
- row5：回答结束后的轻点头和微笑，完整动作约 0.6 秒。
- row6：专注等待或倾听。
- row7：备用的轻微歪头或眨眼。

风格要求：小尺寸下轮廓清楚、动作克制自然、颜色稳定统一。禁止空格、重复粘贴同一帧、相邻帧残影、裁断身体或用整体抖动代替动作。
```

## 配套 JSON

复制下面模板，只修改 `name`、`sprite` 和确实需要调整的速度。`row/from/to` 不应偏离标准动作表。

```json
{
  "name": "显示名称",
  "sprite": "example.png",
  "grid": { "cols": 8, "rows": 8 },
  "defaultFps": 10,
  "levelGain": 8,
  "states": {
    "idle":    { "row": 0, "from": 0, "to": 7, "loop": true,  "durations": [1500, 180, 80, 180, 80, 80, 80, 900] },
    "talk":    { "row": 1, "from": 0, "to": 7, "loop": true,  "fps": 12 },
    "wave":    { "row": 2, "from": 0, "to": 7, "loop": false, "fps": 10 },
    "jump":    { "row": 3, "from": 0, "to": 7, "loop": false, "fps": 10 },
    "failed":  { "row": 4, "from": 0, "to": 7, "loop": false, "fps": 9 },
    "review":  { "row": 5, "from": 0, "to": 7, "loop": false, "fps": 14 },
    "waiting": { "row": 6, "from": 0, "to": 7, "loop": true,  "fps": 6 },
    "spare":   { "row": 7, "from": 0, "to": 7, "loop": true,  "fps": 6 }
  },
  "mapping": {
    "idle": "idle", "starting": "waiting", "listening": "idle",
    "wake-active": "idle", "sleep": "idle", "speaking": "talk",
    "recording": "waiting", "waiting-activation": "waiting"
  }
}
```

字段说明：

- `durations`：可选，每个画面的停留毫秒数；缺省时使用 `fps`。
- `levelGain`：可选，口型音量增益；建议从 `8` 开始，只在实际声音始终张不开嘴时逐步增大。
- `lift`：可选，仅用于素材本身没有垂直位移的跳跃行；标准素材不需要。
- `safeCrop`：仅用于兼容已有越格素材，可分别裁掉 `top/right/bottom/left` 的源图像素；新标准素材禁止依赖该字段。

## 验收清单

- [ ] PNG 是 1024×1024、RGBA 透明背景，可被 8×8 精确整除。
- [ ] 64 格都有且只有一个完整的同一角色，单元格四边至少 10px 透明。
- [ ] 所有人物的中心、脚部基线和基础比例一致，没有相邻帧残影。
- [ ] row1 从闭口到最大张口严格递增，并且只有嘴发生变化。
- [ ] row3 只做垂直跳跃，没有横移或缩放。
- [ ] row5 是克制的轻点头与微笑，不是翻书或长时间动作。
- [ ] PNG 与 JSON 同名，`sprite` 指向实际文件，所有状态帧范围都在 0–7。
- [ ] 放入 `public/pets/` 后能自动出现、切换、说话、挥手、跳跃并回到待机。

任一项不满足就重新生成，不能依靠运行时掩盖不合格的新素材。
